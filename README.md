# unclesigma-visualizers

Moving backgrounds for Uncle Sigma, built with three.js. Used by the site's Lock-in page and 4K recorder, and by the stream. Each scene is a deterministic function of time. Source only, no build.

```bash
npm install
npm run check   # type check
```
